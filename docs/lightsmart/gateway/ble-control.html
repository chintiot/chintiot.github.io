BLE Mesh 控制指令格式 (ble_in) ​

hapi 下发的控制指令为十六进制字符串，整体结构：

53 {msgType} {cmdLen} {naddr_le} {opcode} {data} {xor}
字段长度说明
531 字节固定帧头
msgType1 字节消息类型（30=控制, 32=查询, 0c=登录, 04=Mesh配置）
cmdLen1 字节负载长度
naddr_le2 字节网络地址（小端序），广播地址=bcc0
opcode1 字节操作码
data可变指令参数
xor1 字节全帧异或校验和

详细的 genCommand 指令对照表（含 cmdLen、参数格式、hex 示例）见附录 BLE Mesh 指令帧。

开关控制 ​

操作opcodehex 示例说明
开02533004{naddr}02{status_byte}{xor}status_byte 见下方编码
关02533004{naddr}02{status_byte}{xor}
插卡取电开关02533004{naddr}02{status_byte}{xor}cmdLen=04，同开关格式

status_byte 编码（4 路，msgType=02）：

bit 7 6 5 4 3 2 1 0
     [4][3][2][1]    每路 2 bit: 10=开, 01=关, 00=不变

8 路开关（oe=true）使用 cmdLen=05、msgType=45，额外一个字节编码 5-8 路。

空调组合指令 (setACAdv) ​

一次性设置模式+温度+风速，cmdLen 根据参数动态计算：

53 30 {cmdLen} {naddr} 02 02 [1d {mode}] [1b {temp}] [1c {speed}] {xor}

naddr 编码 ​

encodeNaddr(naddr) 将设备的网络地址编码为 2 字节小端序 hex：

javascript
const str = naddr.toString(16).padStart(4, '0');
return str.substring(2, 4) + str.substring(0, 2);

naddr 是 BLE Mesh 中的单播地址，范围 0x0001-0x7FFF。广播地址为 bcc0。

签名 ​

signCommand(cmd) 对整个命令体（含帧头）计算异或校验和，附加在末尾：

javascript
let xor = 0;
for (let i = 0; i < cmd.length; i += 2) {
  xor ^= parseInt(cmd.substring(i, i + 2), 16);
}
return xor.toString(16).padStart(2, '0');

网关收到指令后会验证签名，签名不匹配的指令将被丢弃。

BLE OTA 命令 ​

BLE Mesh 帧还支持子设备固件升级相关命令：

msgType说明用途
04OTA 开始发起子设备固件升级
05OTA 数据分块发送固件数据
06OTA 结束完成固件升级
0cMesh 配置配网/meshkey 设置

网关通过 system 主题 mstype=15 接收 OTA 会话列表后，使用上述 BLE Mesh 帧逐个对子设备执行固件升级。
