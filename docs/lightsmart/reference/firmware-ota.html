固件 OTA 地址 ​

固件信息存储在阿里云 OSS（公共读），小程序通过 firmware/{pid}/upgrade_par.json 检查升级，网关通过 firmware/{pid}/ 下载固件二进制文件。

OTA 升级流程 ​

小程序                          OSS                          网关                        子设备
  |                              |                             |                            |
  |--- GET firmware/{pid}/upgrade_par.json --->|               |                            |
  |<-- fw_url, fw_ver, ... -------|             |                            |
  |                              |                             |                            |
  |--- systemPublish(mstype=15) via MQTT ----->|-------------→|                            |
  |                              |              |--- 下载 fw_url (HTTP) ----→|             |
  |                              |              |<-- 固件二进制 --------------|             |
  |                              |              |--- BLE 刷写子设备 -----------------------→|
  |<-- register code=2001 (进度) via MQTT ------|-------------|                            |
  |                              |              |                             |            |
  |                              |              |                             --- 刷写完成 |
  |<-- register code=2001 (status=5 升级成功) ---|-------------|                            |

网关升级（特殊） ​

网关插座（type=200）的升级方式与子设备不同：

  1. 小程序调用 POST /hotel/device/set_upgrade（携带 file_id）通知后端
  2. 小程序通过 systemPublish(mstype=9) 通知网关执行升级
  3. 网关自行从后端获取固件并刷写

网关的 upgrade_par.json 中没有 fw_url，而是 file_id（后端通过该 ID 定位固件文件）。

子设备升级 ​

子设备（开关、窗帘等）的升级通过 systemPublish(mstype=15) 下发指令，固件 fw_url 直接由网关从 OSS 下载（HTTP 公共读）。

固件地址表 ​

OSS 基础路径：http://chint-beancomm-content.oss-cn-shanghai.aliyuncs.com

固件元数据：/firmware/{pid}/upgrade_par.json（JSON，公共读）

固件二进制：/firmware/{pid}/{fw_name}（bin 文件，公共读）

upgrade_par.json 字段说明 ​

字段类型说明
fw_urlstring固件二进制下载地址（子设备有，网关无）
fw_namestring固件文件名
fw_verstring固件版本号
fw_notestring更新说明
dev_namestring[]设备名称标识（如 YiZSW、YiZCT、YiCTW）
forceboolean是否强制升级（非必须）
force1boolean是否强制升级（开关/窗帘类使用）
file_idnumber固件文件 ID（仅网关，后端通过此 ID 定位固件）
<{version}string低于该版本的提示信息（如 <1.1.0）

固件命名规则 ​

前缀芯片设备类型
BCB22_YiZSWBCB22开关（一位/二位/三位/四位）
BCB22_YiZCTBCB22窗帘开关（一位/二位）
BCB22_YiCTWBCB22窗帘电机
BCB22_YiZDMBCB22调光调色开关
BCB22_YiZLTBCB22筒射灯
BCB02(TL)_BduSWBCB02旧版四位开关

BCB22 为新一代芯片，BCB02 为旧一代芯片。同一设备类型可能有两个 pid 对应新旧两代硬件。
