设备类型代码 ​

type 数字代码（hapi 内部） ​

hapi 的 device_info 中每个设备都有 type 字段，用于区分设备类型：

type设备说明
1零火开关BLE Mesh 开关
2单火开关BLE Mesh 开关
4智能灯支持亮度调节
5窗帘电机支持开/关/停/位置
9插卡取电
10温控器/红外payload.type 区分子类型
22集控亮度灯hapi deviceTypeArr[22]='smart_light_c'；deviceTypeNames[22]='集控亮度灯'

小程序设备标识（device_info key） ​

key中文名说明
wangguanchazuo网关插座Zigbee 网关，作为 Mesh 主节点
kaiguan1 / kaiguan2 / kaiguan3 / kaiguan4一/二/三/四位开关BLE Mesh 开关，按按键拆分
dimmingcontroller调光灯支持亮度调节
tiaoguang2调光调色灯支持亮度+色温调节
curtainmotor窗帘电机支持开/关/停/位置
chunagliankaiguan*窗帘开关控制窗帘的开关面板
renticunzai人体存在传感器人体感应检测
ble_lock蓝牙门锁通过 system topic 控制

修订记录 ​

  • 2026-09-26 代码回源修正（依据 service-lightsmart-hapi/src/common/device.js:2、app-lightsmart-ztutil/src/protocol.js:20-40、hapi/src/utils/device.js:489-506、hapi/src/service/beancomm.js:1500-1527）：
    • type 22 由「插卡」更正为 smart_light_c（集控亮度灯）；「插卡取电」为 type 9。
    • 零火开关 on_off 编码由 on(01)/off(00) 更正为 on(10)/off(01)（每路 2 bit，2=开 / 1=关）。原写法按文档实现会导致开关反相。

物模型定义 ​

零火开关 (type=1) ​

属性

属性名opcode取值范围说明
on_off02on(10=2) / off(01=1)开关状态（每路 2 bit；00=不变）

服务：开 / 关（按路 index 控制）

事件：状态变更 → 上报 on_off

智能灯 ​

属性

属性名opcode取值范围说明
on_off02on / off开关状态
brightness030-100亮度百分比
colour_temperature040-100色温
sub_brightness9c0-100[]子灯亮度（按索引）
rgb4c6 字节 hexRGB 颜色

服务：开 / 关 / 设置亮度 / 增减亮度 / 设置色温 / 增减色温 / 设置子灯亮度 / 增减子灯亮度 / 设置子灯色温 / 增减子灯色温

窗帘电机 (type=5) ​

属性

属性名opcode取值范围说明
curtain_run05open(01) / close(02) / stop(03)运行状态
position060-100位置百分比

服务：开窗帘 / 关窗帘 / 停窗帘 / 开到位置 / 关到位置

温控器 ​

属性

属性名opcode取值范围说明
on_off02on / off开关
ac_temperature1b16-30空调温度
ac_wind_speed1chigh / middle / low / auto风速
ac_mode1dcold / warm / fan / auto模式

服务：开 / 关 / 设置温度 / 增减温度 / 设置模式 / 设置风速 / 增减风速 / 组合设置(setACAdv)

红外遥控 ​

属性

属性名opcode说明
ir_data8f红外编码数据

服务：开/关(TV/机顶盒) / 增减音量 / 静音 / 增减频道 / 切换频道 / 红外学习

门磁传感器 ​

属性

属性名opcode取值范围说明
door_sensor0aopen / close门磁状态

事件：开门 → door_sensor=open / 关门 → door_sensor=close

人体感应 ​

属性

属性名opcode取值范围说明
human_body0ctrue / false人体存在

事件：人体检测 → human_body=true / 人体离开 → human_body=false

插卡取电 ​

属性

属性名opcode取值范围说明
plug_card0e有卡 / 无卡插卡状态

data 值：00=无卡, 01=有卡, 02=上电插卡虚拟事件, 03=无卡取电拔卡

温度传感器 ​

属性

属性名opcode取值范围说明
sensor_temperature16-40~85环境温度（℃，2 字节有符号小端序 / 100）

场景 ​

场景不是物理设备，通过 BLE Mesh 广播地址执行。

服务：执行场景 → genExecuteScene(scene_id) → 广播地址 bcc0 + 01 + sceneId_hex

透传 ​

服务：透传 → opcode 15 + 原始 hex 数据
